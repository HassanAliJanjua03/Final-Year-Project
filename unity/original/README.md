# Original Unity snippets

[Z_Slide.cs](Z_Slide.cs) moves the assembly in world Z, handles forward/backward flags and reacts to limit-switch tags. [ZSlide_Ctrl.cs.txt](ZSlide_Ctrl.cs.txt) is the incomplete supplied excerpt; it is intentionally stored as text rather than presented as compilable source. The original Unity project uses Unity 2019.3.5f1. These snippets implement manual virtual movement, not an InfluxDB data client.
