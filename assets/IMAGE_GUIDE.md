# Adding my pictures and videos

All project photo slots are linked to fixed filenames. The image files are intentionally absent until I upload my own pictures. No README editing is needed for the listed files.

## Pictures

1. Prepare the photos as actual PNG files. Convert JPG or WebP to PNG first; renaming an extension alone does not convert it.
2. Open [the image upload page](https://github.com/HassanAliJanjua03/Final-Year-Project/upload/main/assets/images).
3. Rename each picture to the exact filename below and upload it. I can upload multiple pictures in one operation.
4. Commit to main, or merge the pull request if GitHub requires one. The pictures will appear automatically in the main README, project gallery and relevant module documentation. Until uploaded, GitHub may show a missing image icon or alt text.

## Videos

Upload MP4 files to [the demonstration upload page](https://github.com/HassanAliJanjua03/Final-Year-Project/upload/main/demonstrations) and use these filenames:

| Demonstration | Filename in demonstrations/ |
| --- | --- |
| Physical robot in motion | `physical_robot.mp4` |
| Unity 3D digital twin demonstration | `unity_digital_twin.mp4` |
| InfluxDB and Grafana demonstration | `influxdb_grafana.mp4` |

The main README and module pages already link to these files. GitHub may display the file page or offer a download instead of playing it inline. Browser uploads are limited to 25 MiB per file; use GitHub Desktop or Git for larger supported files. GitHub blocks regular Git files above 100 MiB, so use Git LFS or an external video host for larger files. Review recordings for incidental private information before uploading.

## Replacing or removing media

To replace an already uploaded file, use GitHub Desktop to copy over the file with the same name, then commit and push. If a browser upload refuses an overwrite, GitHub Desktop is the simplest option. Removing a media file leaves its slot empty again; it can be restored by uploading the same filename.

The SVG design graphics are separate from the photo slots. Leave them unchanged to preserve the layout.
